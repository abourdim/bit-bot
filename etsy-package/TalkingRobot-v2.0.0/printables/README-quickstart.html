Thank you for buying Talking Robot! You just grabbed a zero-install, zero-account, browser-local AI voice companion for kids. Everything runs on your machine — no cloud, no telemetry, no nonsense. This page walks you through the first three things to do.

First 3 Things To Do

1
Open the kid app. Double-click index_kids.html in Chrome or Edge. It loads locally. (The full grown-up app is at index.html if you want every setting in one place.)
2
Name the robot & pick a personality. Give it a name, then choose Playful, Helpful, Pirate, or Space Explorer. Tap the mic and start chatting — or use offline demo mode if you don’t have an OpenAI key.
3
Optional: pair a micro:bit. Flash microbit_makecode.js (or v2/v3) from makecode.microbit.org to a BBC micro:bit V2, then click Connect in settings. The robot’s face mirrors onto the 5×5 LED matrix. Totally optional — skip if you don’t own one.
