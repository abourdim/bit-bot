Sample Lesson: Build a Character — Your First AI Robot Friend

Ready-to-teach 45-minute example
Build a Character — Your First AI Robot Friend
45 minutes
Ages 5–12
Digital Literacy / Creative Writing / AI Awareness
Learning Objectives
1. Create an original robot character (name + personality).
2. Have a short conversation with an AI and describe how it felt.
3. Experiment with swapping personalities and notice the difference.
4. Practice respectful, kind language when talking to an AI.
Materials
  • 1 laptop per pair, Chrome or Edge, microphone enabled
  • Talking Robot opened via index_kids.html
  • (Optional) 1 BBC micro:bit V2 per pair — to mirror the robot face on the 5×5 LED
  • Sticker sheet for completion rewards

Talking Robot features used in this lesson

  • Custom Robot Name students make the robot theirs
  • 4 Personalities Playful, Helpful, Pirate, Space Explorer
  • Voice + Text Chat speak or type — both work
  • Offline Demo Mode perfect if no API key is available
  • Optional LED Face Mirror pair a micro:bit V2 to see the robot face on the 5×5 LED
