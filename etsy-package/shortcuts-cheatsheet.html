Talking Robot Cheat Sheet

Voice Commands, Keyboard & Parental Controls — Laminate Me!
Print → Laminate → Stick near the computer
Voice Commands (say these)
"tell me a joke"Robot tells a kid-safe joke
"what time is it"Robot announces the local time
"change personality"Opens the 4-personality picker
"be a pirate"Switches to Pirate on the spot
"be playful"Switches to Playful
"be helpful"Switches to Helpful
"be a space explorer"Switches to Space Explorer
"be quiet"Mutes TTS for this reply
"bye bye"Ends the session, saves history
Keyboard Shortcuts
EnterSend the typed message
SpaceToggle the mic (start / stop listening)
EscClose the current modal / overlay
?Show shortcuts help
TToggle Dark / Light theme
Parental Controls
Set the PIN: Settings → Parental Controls → Set PIN (4 digits).
Open settings: gear icon (top right) → enter PIN.
AI on / off: Settings → AI Chat toggle. When off, the robot uses offline phrase packs only.
Usage timer: Settings → Usage Limit. Set minutes per day; auto-locks when reached.
Review history: Settings → Conversation History. Read or delete any of the last 20 sessions.
Clear history: Settings → Conversation History → Clear All.
API key: Settings → OpenAI Key. Stored only on this device.
4 Personalities
🎈Playful — silly jokes, big energy, loves games
🧑‍🏫Helpful — calm, patient, answers questions clearly
🏴‍☠️Pirate — "arrr!" sea tales, treasure and puns
🚀Space Explorer — star facts, cosmic missions
micro:bit Pairing (optional)
Disconnected — no board attached, app is fully usable
Pairing — choose "BBC micro:bit [xxxxx]" in the browser prompt
Connected — robot face mirrored live on the 5×5 LED
Error — auto-retry, then re-pair from Settings
Scan the in-app QR code to jump straight to the MakeCode project and flash your micro:bit V2.
Robot Face Moods
😊Happy — chatting, answering
👂Listening — mic is live
🤔Thinking — waiting for AI
😮Surprised — unexpected input
😴Sleepy — idle / usage limit
Pro Tips
No API key? Turn on Offline Demo Mode in Settings for phrase-pack replies. Only Chrome / Edge support the mic & Web Bluetooth features.
