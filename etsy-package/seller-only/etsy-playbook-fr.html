Description complète

🤖 Talking Robot — un compagnon vocal IA pour enfants qui fonctionne directement dans le navigateur. Nommez votre robot, choisissez une personnalité, appuyez sur le micro — et il répond. Sans installation, sans compte, sans app store. Optionnel : appairez un BBC micro:bit V2 en Bluetooth pour refléter le visage du robot sur la matrice LED. CE QUE VOUS OBTENEZ • 🎙 Chat vocal (reconnaissance vocale + synthèse vocale avec aperçu des voix) • 🤖 4 personnalités : Joueur · Serviable · Pirate · Explorateur de l'Espace • 🧠 Mode IA via OpenAI (votre propre clé) OU mode démo hors ligne avec phrases prédéfinies • 🎨 Visage SVG animé (yeux, antenne, bouche) • 🔐 PIN parental sur chaque réglage • ⏱ Minuteur d'utilisation + bascule IA on/off • 💬 Historique des conversations — jusqu'à 20 sessions sauvegardées localement pour revue parentale • 📡 Miroir LED micro:bit V2 optionnel (visage sur la matrice 5×5) via Web Bluetooth • 📲 QR code vers le firmware MakeCode pour une configuration rapide du micro:bit • 🌗 Thèmes clair & sombre (clair kid-friendly par défaut) • 📱 PWA — installable, utilisable hors ligne • ♿ Accessibilité : liens d'évitement, ARIA, navigation clavier CONTENU DU TÉLÉCHARGEMENT • index_kids.html — interface pour enfants • index.html — appli complète avec tous les réglages • microbit_makecode.js / v2 / v3 — trois variantes de firmware pour le miroir LED optionnel • docs/ — guide utilisateur, aide-mémoire, guide contrôles parentaux, FAQ, playbook Etsy • Imprimables — carte de démarrage rapide, aide-mémoire, poster A3, plan de leçon, feuille d'autocollants • LICENSE — licence famille unique / classe unique PRÉREQUIS • Un navigateur moderne (Chrome ou Edge recommandé pour la saisie vocale) • Micro + haut-parleurs pour le chat vocal (taper fonctionne aussi) • Optionnel : clé API OpenAI pour le mode IA intelligent — le mode démo hors ligne marche sans • Optionnel : BBC micro:bit V2 pour le miroir LED du visage POUR QUI Parents d'enfants de 6 à 12 ans · familles en école à la maison · clubs extra-scolaires · trajets en voiture · enseignants souhaitant un compagnon de chat kid-safe sur les Chromebooks de la classe. CONFIDENTIALITÉ D'ABORD Fonctionne localement. Pas de compte, pas d'analytique, pas de cloud. L'historique et les réglages restent dans votre navigateur. La seule requête sortante est la demande IA optionnelle avec votre propre clé — et l'IA peut être totalement désactivée. MISES À JOUR À VIE Chaque version publiée depuis cette annonce est à vous pour toujours. Retéléchargez le dernier ZIP à tout moment depuis votre page Achats Etsy. Bon chat ! 🤖💬✨
