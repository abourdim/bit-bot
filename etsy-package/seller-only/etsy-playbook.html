Full description

🤖 Talking Robot — an AI voice companion for kids that runs right in the browser. Name your robot, pick a personality, press the mic — and it talks back. No install, no sign-in, no app store. Optional: pair a BBC micro:bit V2 over Bluetooth to mirror the robot's face on the LED matrix. WHAT YOU GET • 🎙 Voice chat (speech recognition + text-to-speech with voice preview) • 🤖 4 personalities: Playful · Helpful · Pirate · Space Explorer • 🧠 AI mode via OpenAI (bring your own key) OR offline phrase-pack demo mode • 🎨 Animated SVG robot face (eyes, antenna, mouth) • 🔐 Parental PIN on every setting • ⏱ Usage timer + AI on/off toggle • 💬 Conversation history — up to 20 sessions saved locally for parent review • 📡 Optional micro:bit V2 LED mirror (face on the 5×5 LED) via Web Bluetooth • 📲 QR-code link to the MakeCode firmware for quick micro:bit setup • 🌗 Dark & light themes (kid-friendly light by default) • 📱 PWA — installable, offline-capable • ♿ Accessibility: skip links, ARIA, keyboard nav WHAT'S IN YOUR DOWNLOAD • index_kids.html — kid-friendly UI • index.html — full app with every setting • microbit_makecode.js / v2 / v3 — three firmware variants for the optional LED mirror • docs/ — user guide, cheat sheet, parental-controls guide, FAQ, Etsy playbook • Printables — quick-start card, shortcuts cheat sheet, A3 robot poster, lesson plan, sticker sheet • LICENSE — single-family / single-classroom license REQUIREMENTS • Any modern browser (Chrome or Edge recommended for voice input) • Microphone + speakers for voice chat (typing works too) • Optional: OpenAI API key for smart AI mode — offline demo works without one • Optional: BBC micro:bit V2 for the LED face mirror WHO IT'S FOR Parents of kids 6–12 · homeschool families · after-school clubs · quiet car rides · teachers who want a kid-safe chat companion on classroom Chromebooks. PRIVACY FIRST Runs locally. No accounts, no analytics, no cloud. Conversation history and settings live in your browser and on your disk. The only outbound call is the optional AI request using your own API key — and you can turn AI off entirely. LIFETIME UPDATES Every version shipped from this listing is yours forever. SLUG — AVOID THESE

Common mistakes

❌ Don't✅ Do
Start with "Hi, I'm…" + 10s of introOpen with the kid saying "hi!" and the robot replying in the first 3 s
Film landscape (16:9)9:16 portrait — Etsy autoplays on mobile
Talk over the robot's voice lineLet the robot's reply breathe for 1–2 s, then add your voiceover
Forget captions (Etsy plays muted)Burn in captions for both the kid's prompt and the robot's reply
Show voice chat on Safari / iOSAlways demo on Chrome/Edge for voice — Safari buyers will refund
Skip the CTASay "link below" in the last 5 seconds every single time
